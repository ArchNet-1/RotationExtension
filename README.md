# ArchNet · Rotation Extension

Spins its GameObject around an axis at a set speed (loading icons, coins, fans…).

- Unity **6000.0** or newer · No dependency.
- Part of [ArchNet](https://archnet-plateform.fr), free and open-source Unity packages

## Install

*Window > Package Manager > + > Install package from git URL…*

```
https://github.com/ArchNet-1/RotationExtension.git
```

## Use

Add **ArchNet > Rotation**, set speed (degrees per second) and axis. `Play()` / `Stop()` from code or UnityEvents.
